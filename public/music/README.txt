Background music for Reggie
===========================

Put your music file in this folder and name it exactly:

    background.mp3

It loops quietly while the "Music" toggle in Settings is on (off by default).
Keep it small (ideally under 3 MB; use a 96-128 kbps mp3) so it loads fast on phones.
Only use music you own or have a licence to use.

To use a different file name, change MUSIC_SRC in src/lib/music.ts.
